MA SHAMSUNDARI ONLINE SERVICES - PREMIUM ONLINE BILLING

Features:
- Firebase Email/Password login
- Firestore bill saving and history
- Customer edit
- Online service billing
- Print / Save PDF in the provided Cash Bill / Money Receipt design
- WhatsApp bill sharing
- Mobile-friendly dashboard

Firebase setup:
1. Put the real apiKey in firebase-config.js.
2. Enable Authentication > Sign-in method > Email/Password.
3. Create the admin user in Authentication > Users.
4. Firestore rules included allow authenticated users to read/write bills.

Print:
The bill uses the supplied Ma Shamsundari Online Services reference format. Print with A4 Landscape and background graphics enabled for the closest result.
